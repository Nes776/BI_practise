# BI_practise

##  Технологии и инструменты
- **Yandex DataLens** — основной инструмент: чарты, таблицы, KPI-виджеты, фильтры, вычисляемые поля, дашборды.
- **Microsoft BI** — дополнительный опыт: Power BI (DAX, модели данных), SSAS/SSRS (базовые навыки).
- **SQL** — подготовка, агрегация и расчёт метрик.
- **Data Analysis** — исследовательский анализ, выявление закономерностей, автоматизация отчётности.
- **Process Mining** — анализ бизнес-процессов, расчёт потенциала автоматизации.

---

##  Реализованные дашборды

### 1. ВВП (ППС) на душу населения по столицам мира (2023/20)
- **Круговая диаграмма**: распределение ВВП по столицам (Вашингтон, Берлин, Канберра, Оттава, Париж, Рим, Лондон, Мадрид, Токио, Москва, Анкара).
- **Столбчатая диаграмма**: сравнение столиц по ВВП на душу населения.
- **Данные**: макроэкономические показатели, географические координаты, 2023 год.
- **Навыки**: визуализация категориальных данных, сортировка, подписи, проценты, работа с географическими данными.

### 2. Демография и территория: население и площадь по странам и континентам
- **Круговая диаграмма**: доля населения Земли по странам (Китай, Индия, США, Индонезия, Бразилия, Пакистан, Нигерия, Бангладеш, Россия, Япония, Мексика).
- **Столбчатая диаграмма**: площадь по странам (Россия, Канада, Китай, США, Бразилия, Австралия, Индия, Аргентина, Казахстан, Великобритания, Алжир, ДР Конго, Саудовская Аравия).
- **Таблица**: население, % от населения Земли, фильтр по континентам (Азия, Америка, Африка, Европа, Океания).
- **Навыки**: работа с большими наборами данных, фильтрация, агрегация, расчёт процентов, интерактивные срезы.

### 3. Process Mining: анализ длительности и автоматизации процессов
- **KPI-панель**: уникальное количество пользователей (10), уникальное количество процессов (6), количество нераспознанных действий (120), ПШЕ (216,58), минимальная/максимальная длительность процесса.
- **Круговая диаграмма**: вероятность по процессам.
- **Линейный график**: распределение длительности процесса (минимальная, средняя, максимальная).
- **Столбчатая диаграмма**: действия пользователей.
- **Таблица**: минимальная сложность автоматизации и максимальная ПШЕ после автоматизации по проектам процессов (1–10).
- **Фильтры**: год, департамент, имя пользователя, найденный процесс.
- **Навыки**: Process Mining, KPI, интерактивные фильтры, расчёт метрик, визуализация распределений, оценка потенциала автоматизации.
